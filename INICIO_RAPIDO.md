# 🚀 Início Rápido

## Para testar AGORA (Modo Simples)

1. Clique duas vezes no arquivo `index.html`
2. O app abrirá no seu navegador
3. Comece a usar imediatamente! ✅

**Nota:** Neste modo, algumas funcionalidades PWA (como instalação e offline completo) não estarão disponíveis.

---

## Para usar com TODOS os recursos (Recomendado)

### Opção 1: Python (se você tem Python instalado)

1. Abra o terminal/prompt de comando nesta pasta
2. Execute:
   ```bash
   python -m http.server 8000
   ```
3. Abra o navegador e acesse: `http://localhost:8000`
4. Pronto! 🎉

### Opção 2: VS Code Live Server

1. Abra esta pasta no VS Code
2. Instale a extensão "Live Server" (se ainda não tiver)
3. Clique com botão direito no `index.html`
4. Selecione "Open with Live Server"
5. Pronto! 🎉

### Opção 3: Node.js

1. Abra o terminal nesta pasta
2. Execute:
   ```bash
   npx serve
   ```
3. Acesse o link que aparecer (geralmente `http://localhost:3000`)
4. Pronto! 🎉

---

## 📱 Instalar como Aplicativo

Depois de abrir via servidor (Opção 1, 2 ou 3 acima):

1. Procure o botão **"📱 Instalar App"** no canto inferior esquerdo
2. Ou clique no ícone de instalação (➕) na barra de endereços
3. Confirme a instalação
4. Agora você tem um app nativo! 🎊

---

## ✅ Primeiro Uso

1. Clique em **"➕ Novo Erro"**
2. Preencha um erro de exemplo:
   - Disciplina: Português
   - Assunto: Concordância Verbal
   - Questão: "O funcionário ou os funcionários _____ o relatório"
   - Minha Resposta: apresentou
   - Resposta Correta: apresentaram
   - Explicação: Com "ou" inclusivo, o verbo concorda no plural
   - Dificuldade: Médio
3. Clique em **"💾 Salvar"**
4. Explore as outras abas!
