# Política de Privacidade - Caderno de Erros

**Última atualização:** 7 de outubro de 2026

## 1. Introdução

Esta Política de Privacidade descreve como o aplicativo **Caderno de Erros - Concursos Públicos** ("nós", "nosso" ou "app") coleta, usa e protege as informações dos usuários.

Ao usar nosso aplicativo, você concorda com a coleta e uso de informações de acordo com esta política.

## 2. Informações que Coletamos

### 2.1 Dados Armazenados Localmente

O Caderno de Erros é um aplicativo **100% offline** que armazena todos os dados **exclusivamente no dispositivo do usuário**. Não coletamos, transmitimos ou armazenamos dados em servidores externos.

Os dados armazenados localmente incluem:

- **Erros cadastrados**: disciplina, banca, concurso, assunto, questão, respostas e explicações
- **Estatísticas de uso**: número de revisões, datas de cadastro
- **Preferências do usuário**: tema escolhido (claro/escuro)
- **Tags personalizadas**: criadas pelo próprio usuário

Todos esses dados são armazenados usando **localStorage** do navegador ou do aplicativo instalado.

### 2.2 Dados que NÃO Coletamos

Nosso aplicativo **NÃO coleta, acessa ou transmite**:

- ❌ Informações pessoais identificáveis (nome, email, CPF, etc.)
- ❌ Localização geográfica
- ❌ Contatos do dispositivo
- ❌ Fotos ou arquivos de mídia
- ❌ Dados de outros aplicativos
- ❌ Informações de pagamento
- ❌ Histórico de navegação
- ❌ Identificadores de dispositivo (IMEI, endereço MAC, etc.)
- ❌ Dados de uso ou analytics
- ❌ Cookies de rastreamento

## 3. Como Usamos as Informações

Os dados armazenados localmente são usados exclusivamente para:

✅ Exibir os erros cadastrados pelo usuário  
✅ Permitir busca e filtros nos erros  
✅ Gerar estatísticas de estudo  
✅ Possibilitar o modo de revisão  
✅ Manter as preferências do usuário (tema)  

**Importante:** Como todos os dados ficam no seu dispositivo, somente você tem acesso a eles.

## 4. Compartilhamento de Dados

**Nós NÃO compartilhamos, vendemos ou transferimos seus dados para terceiros**, pois:

- Não coletamos dados em servidores
- Não usamos serviços de analytics
- Não temos parcerias de publicidade
- Não integramos com redes sociais

Seus dados permanecem **100% privados** no seu dispositivo.

## 5. Armazenamento e Segurança dos Dados

### 5.1 Local de Armazenamento

Todos os dados são armazenados localmente no dispositivo usando:

- **localStorage** do navegador (para versão web)
- **WebView storage** (para versão instalada como PWA/Android)

### 5.2 Segurança

- Os dados são protegidos pelas medidas de segurança do próprio sistema operacional do dispositivo
- O app não transmite dados pela internet
- Não há risco de interceptação de dados, pois não há comunicação com servidores

### 5.3 Backup e Perda de Dados

**Responsabilidade do Usuário:**

- Você é responsável por fazer backup dos seus dados manualmente
- Se desinstalar o app ou limpar os dados do navegador, os dados serão perdidos
- Recomendamos exportar seus dados periodicamente (instruções no README.md)

## 6. Permissões do Aplicativo

O aplicativo **NÃO solicita nenhuma permissão especial** do dispositivo:

- ❌ Não acessa câmera
- ❌ Não acessa microfone
- ❌ Não acessa localização
- ❌ Não acessa contatos
- ❌ Não acessa galeria de fotos
- ❌ Não acessa arquivos externos
- ❌ Não requer conexão com internet (funciona offline)

## 7. Uso por Menores de Idade

O aplicativo é adequado para todas as idades, incluindo menores de 13 anos, pois:

- Não coleta dados pessoais
- Não tem chat ou comunicação com outros usuários
- Não contém anúncios
- Não contém compras dentro do app
- Todo conteúdo é criado pelo próprio usuário

**Recomendação:** Pais e responsáveis podem supervisionar o uso sem preocupações com privacidade.

## 8. Conformidade com LGPD e GDPR

Nosso aplicativo está em conformidade com:

### 8.1 LGPD (Lei Geral de Proteção de Dados - Brasil)

✅ Não coletamos dados pessoais  
✅ Não há tratamento de dados que exija consentimento  
✅ Usuário tem controle total sobre seus dados (pode apagar a qualquer momento)  
✅ Não compartilhamos dados com terceiros  
✅ Transparência total sobre o funcionamento do app  

### 8.2 GDPR (General Data Protection Regulation - Europa)

✅ Não processamos dados pessoais  
✅ Não transferimos dados para fora da UE  
✅ Usuário tem direito ao "esquecimento" (pode apagar dados localmente)  
✅ Não usamos cookies de rastreamento  

## 9. Conexão com Internet

O aplicativo **pode funcionar completamente offline**. Quando há conexão com internet:

- É usada apenas para carregar o app na primeira vez (arquivos HTML, CSS, JS)
- Depois de carregado, o Service Worker permite uso offline
- **Nenhum dado do usuário é transmitido pela internet**

## 10. Atualizações do Aplicativo

Quando você atualiza o aplicativo:

- Seus dados locais são **preservados**
- Apenas os arquivos do aplicativo (código) são atualizados
- Não há sincronização de dados com servidores

## 11. Exclusão de Dados

Para excluir seus dados:

### Opção 1: Limpar dados do app (Android)
1. Configurações do dispositivo → Apps
2. Encontre "Caderno de Erros"
3. Toque em "Armazenamento"
4. Toque em "Limpar dados"

### Opção 2: Limpar dados do navegador (Web)
1. Abra o Console do navegador (F12)
2. Digite: `localStorage.clear()`
3. Pressione Enter

### Opção 3: Desinstalar o app
- Todos os dados serão removidos automaticamente com a desinstalação

**Nota:** Como os dados estão apenas no seu dispositivo, não precisamos de solicitação formal para exclusão.

## 12. Serviços de Terceiros

O aplicativo **NÃO utiliza nenhum serviço de terceiros**, incluindo:

- ❌ Google Analytics ou similares
- ❌ Firebase, Crashlytics
- ❌ Redes de publicidade
- ❌ Serviços de autenticação (Google, Facebook, etc.)
- ❌ APIs externas
- ❌ CDNs para bibliotecas (tudo está incluído no app)

## 13. Alterações nesta Política de Privacidade

Podemos atualizar nossa Política de Privacidade ocasionalmente. Notificaremos sobre mudanças:

- Publicando a nova política nesta página
- Atualizando a data de "Última atualização" no topo
- Através de um aviso dentro do app (em atualizações futuras)

Recomendamos revisar esta política periodicamente.

## 14. Seus Direitos

Você tem direito a:

✅ **Acesso**: Ver todos os dados armazenados (estão no seu dispositivo)  
✅ **Correção**: Editar qualquer erro cadastrado  
✅ **Exclusão**: Apagar erros individuais ou todos os dados  
✅ **Portabilidade**: Exportar seus dados (função manual via console)  
✅ **Oposição**: Parar de usar o app a qualquer momento  

Como você tem controle total dos dados no seu dispositivo, pode exercer esses direitos diretamente no app.
