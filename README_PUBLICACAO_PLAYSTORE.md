### Obrigatórios para Play Store

✅ **Ícone 512x512** - Use: `gerar-icone-512.html`  
✅ **Screenshots (mín. 2)** - Capture do app usando DevTools  
✅ **Feature Graphic (1024x500)** - Crie no Canva  
✅ **Política de Privacidade** - Já criada! Atualize o email  
✅ **Descrições** - Já prontas em `TEXTOS_PLAYSTORE.md`

### Como Criar Cada Um

**Ícone:**
```
Abra: gerar-icone-512.html → Gerar → Baixar
```

**Screenshots:**
```
1. Abra seu app online (GitHub Pages)
2. Pressione F12 → Device Toolbar
3. Escolha: Pixel 5
4. Ctrl+Shift+P → "Capture screenshot"
5. Capture 2-4 telas diferentes
```

**Feature Graphic:**
```
1. Acesse: canva.com
2. Tamanho: 1024 x 500 px
3. Fundo: #4F46E5 (roxo)
4. Adicione: emoji 📚 + texto "Caderno de Erros"
5. Baixe como PNG
```
